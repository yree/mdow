# Features

## Editor

- Write markdown in-browser
- Live preview (click Preview button)
- Auto-save to browser localStorage

## Sharing

- Generate shareable links via Share button
- Links stored in SQLite for 30 days
- Works without an account

## Viewing

- Rendered markdown page at `/view/:id`
- QR code on shared pages
- Link back to edit in mdow

## Markdown Support

- Standard markdown (headings, lists, code, links, images, tables)
- Task lists
- Strikethrough
- LaTeX math via MathJax
- Syntax highlighting
