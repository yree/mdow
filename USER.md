# User Guide

How to use mdow — for anyone who just wants to write and share markdown.

## Using mdow

1. Open [mdow.yree.io](https://mdow.yree.io)
2. Write or paste your markdown
3. Click **Share** to get a link
4. Share the link — it works for 30 days

Anyone with the link can view and edit the markdown. The link contains the full content, so no account needed.

## Sharing

Shared links are:
- Readable by anyone with the link
- Editable by anyone with the link
- Stored for 30 days, then auto-deleted

Copy the link to share, or bookmark to return later.

## Markdown Support

mdow supports [standard markdown](FEATURES#markdown-support) — click Preview to render.
